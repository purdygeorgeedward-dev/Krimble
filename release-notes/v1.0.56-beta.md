# Krimble 1.0.56-beta

**Your Creative Companion.** Android build for touchscreens, forked from Krita.
Built on GitHub Actions from commit `ad64d9b` (November 11, 2026). Tag: `v1.0.56-beta`.

This build includes everything since 1.0.55-beta (November 9). Build 56 was never released on its own; it was run again for bug fixes.

---

## Look and feel

- **New flat "Krimble dark" theme.** One blue-gray color family; only the brightness changes from the top bar to the panels, lists, tabs and fields. Everything that is selected glows with a bright cyan edge and is dark navy inside (selected tabs, pressed, checked and default buttons, selected menu items, checked boxes).
- **"Krimble Painted" theme.** The earlier gradient look stays available as its own theme in Preferences.
- **Selected tool.** A square with sharp corners that still glows, with a softer glow.
- **Orange K** is back at the left end of the menu bar, sized and placed to fit. The menu bar is no longer forced taller.
- **Swatch lines.** The black lines between color wells and palette swatches are back and no longer disappear when a panel is small.
- **Percentage bars** are shaded from left to right with a glow at the end of the fill.
- **Number fields** change when you drag a finger sideways on them.
- **Preferences:** the keyboard icon is a new picture of a keyboard seen at an angle.

## Color

- **Color Lab:** a strict square color area, a thinner hue strip, rounded foreground and background wells.
- **Tap a color well** in the toolbox to open Color Lab and edit that color.
- **Hex box:** type a color with or without the `#`, six digits are applied as you type, three digits when you finish. No Enter needed.
- **QuickAdjust:** all sliders are the same blue except Hue. The Hue slider is centered on your foreground color's hue, so every position shows the hue it will give. Steel ball-bearing handles. A smaller Preview switch.

## Gradients

- The gradient starts as **Foreground to Background** (it used to fade to transparent).
- **Gradient tool options** now have the full chooser: thumbnails, tags, search, add, import, delete, and **Edit...** for the multi-point stop editor.
- The chooser opens on the gradient that is in use.
- The gradient editor can stretch and opens as wide as the screen.

## CMYK

- **Edit > Custom CMYK...** (first step of the CMYK interface): ink presets, dot gain (standard or your own curve), GCR and UCR separations, black generation, black and total ink limits, UCA, black point compensation, and saving and loading your settings. The dialog fits a phone screen.
- **Smoother separations:** black is a smooth function of how dark a color is, so gray ramps no longer wiggle.

## Tools

- **Undo button** now appears in the toolbox.
- **Free Rotate:** the handles and outline turn with the picture while your finger is down.

## Removed or changed

- The thank-you line to Oracle Cloud is gone from About.
- The **DPaint panel** is switched off (it is not in the Window menu any more).

## Under the hood

- Builds run on GitHub Actions. The native build error scan no longer shows a false "compile error" for the line "Internal error: 0".
- Release signing is with the Krimble release key.

---

## Known issues

- Channels panel: loading a channel as a selection and showing one channel alone are not done yet.
- Transparent text can export differently from how it looks on the canvas.
- The JPEG options dialog and the floating image window need a visual pass.
- Image Size dialog uses more horizontal space than it needs.
- The CMYK interface is partial: Ink Colors, Color Settings, Convert to Profile and printer profiles are still to come, and converting a whole image is slow.

## Install

Download `Krimble-1.0.56-beta-<date>-<time>.apk` from the build artifacts, copy it to your phone and open it. Android may ask you to allow installs from your file manager or browser.
