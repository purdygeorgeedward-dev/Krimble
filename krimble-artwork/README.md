# Krimble artwork (originals)

George's original pictures (512 x 512 PNG, transparent background), kept here at full size. The program uses smaller copies made from them.

- `preferences/` - the 12 pictures for the pages of Edit > Preferences: general, display, tablet, user-identity (Author), keyboard, color-manage (Color Management), canvas-only, color-selector (Color Selector Settings), canvas-input, performance, popup-palette (Pop-up Palette), spen-remote (S-Pen Actions).
- `new-document/` - the 7 pictures for the sections of File > New: custom-document, create-from-clipboard, animation, comics, design, dslr, texture; and `design-monitor-spare.png`, a second picture for Design Templates that is not used.

Where the copies are:
- Preferences: `krita/pics/svg/dark_config-*.svg` and `light_config-*.svg`, `dark_user-identity.svg`, `light_user-identity.svg`, `dark_krimble-config-color-selector.svg`, `light_krimble-config-color-selector.svg`, and `plugins/extensions/spensettings/spen-remote.svg`. Each is an SVG file that embeds a 192 px copy of the picture (the file names stay the same so nothing in the program had to change).
- New Document: `krita/data/templates/<section>/dark_template_*.png` and `light_template_*.png` (256 px), and `krita/pics/svg/dark_krimble-new-document.png`, `light_krimble-new-document.png`, `dark_krimble-new-from-clipboard.png`, `light_krimble-new-from-clipboard.png` (256 px).

## 3D icon set (2026-10-23)

`3d/` - 22 icons cut out of George's 3D icon sheet (Oct 23), 512 x 512 PNG, transparent background: general, keyboard, canvas-input, display, color-manage, performance, tablet, canvas-only, popup-palette, color-selector, spen-remote (the Preferences pages), custom-document, create-from-clipboard, animation, comics, design, dslr, texture (the File > New sections), and language, resource-paths, advanced-settings, reset-restore (not used yet). The robot head and the Author picture are not from this sheet (see `file-info/` and `preferences/user-identity.png`).

The program uses copies of them in the same places as the earlier pictures (listed above; the 2026-10-13 pictures stay in `preferences/` and `new-document/`): Preferences as SVG files embedding a 192 px copy, File > New as 256 px PNG files. All six Design template pictures are the same picture.

2026-10-25: `3d/keyboard.png` is now George's own keyboard picture (cut to its edges, centred, 512 x 512; his picture itself, 1200 px wide, is `3d/keyboard-george-2026-10-25.png`). The keyboard of the 3D icon sheet is kept as `3d/keyboard-first-2026-10-23.png`. It is the icon of Preferences > Keyboard Shortcuts (`krita/pics/svg/{dark,light}_config-keyboard.svg`, embedded at 384 px, shown at 192).
