# Krimble artwork (originals)

Pictures made for Krimble, kept here at full size. The program uses smaller copies made from them. Only pictures that the program uses, or that George asked to keep, are here: the others were removed on 2026-10-25 (294th entry in `KRIMBLE_CHANGES.md`) and can still be found in the git history.

## Used by the program

- `3d/` - the pictures for the pages of Edit > Preferences (512 x 512 PNG, transparent background): general (George's house picture, 2026-10-25), keyboard (George's keyboard picture, 2026-10-25; the picture as he sent it is `keyboard-george-2026-10-25.png`), canvas-input, display, color-manage (Color Management), performance, tablet, canvas-only, popup-palette (Pop-up Palette), color-selector (Color Selector Settings), spen-remote (S-Pen Actions). The others came from the 3D icon sheet of 2026-10-23.
- `new-document/` - the 7 pictures for the sections of File > New (the pictures of 2026-10-13): custom-document, create-from-clipboard, animation, comics, design, dslr, texture. The picture for create-from-clipboard was replaced on 2026-10-25 by George's clipboard with the pencil sketch (the rainbow clipboard was removed; it is in the git history).
- `file-info/author-robot.png` - the robot head: the picture of Edit > Preferences > Author, and of the Author part of File > File Information.

Where the copies are:
- Preferences: `krita/pics/svg/dark_config-*.svg` and `light_config-*.svg`, `dark_user-identity.svg`, `light_user-identity.svg`, `dark_krimble-config-color-selector.svg`, `light_krimble-config-color-selector.svg`, and `plugins/extensions/spensettings/spen-remote.svg`. Each is an SVG file that embeds a copy of the picture (192 px; 256 px for the house, 384 px for the keyboard), so the file names stay the same and nothing in the program had to change. The dark and light files of a picture are the same.
- New Document: `krita/data/templates/<section>/dark_template_*.png` and `light_template_*.png` (256 px), and `krita/pics/svg/dark_krimble-new-document.png`, `light_krimble-new-document.png`, `dark_krimble-new-from-clipboard.png`, `light_krimble-new-from-clipboard.png` (256 px).
- Author: `krita/pics/svg/dark_krimble-file-info-author.svg`, `light_krimble-file-info-author.svg`, `dark_user-identity.svg`, `light_user-identity.svg`.

## Kept, not used by the program

- `emoji/` - `krimble-emoji-32.png` and `krimble-emoji-64.png`, George's K and paw logo "for use as Krimble emojis" (server, forum, browser tab), saved at his request (173rd entry).
- `krita/pics/tools/krimble-future-icons/` - the icons of Pencil, Path Selection and Clone Stamp, for when those tools are added (see the README there).

## Removed on 2026-10-25 (in the git history)

- `preferences/` (the 12 Preferences pictures of 2026-10-13, replaced by the 3D ones, except Author, which is the robot head).
- From `3d/`: animation, comics, create-from-clipboard, custom-document, design, dslr, texture (the 3D versions for File > New, not used since the New dialog went back to the 2026-10-13 pictures), advanced-settings, language, reset-restore, resource-paths (never used), keyboard-first-2026-10-23 and the house of the sheet.
- `new-document/design-monitor-spare.png` (a second Design picture, never used).
