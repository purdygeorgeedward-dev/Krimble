# Krimble design rules (George's standing rules for how things look)

- **Title logos are never centered. Left align them.** (George, 2026-11-08: "Do not center title logos. THIS IS A RULE. LEFT ALIGN.") The left edge of the logo's first letter is on the same vertical line as the left edge of the content under it (for the Color Lab header: the left edge of the first tab).
