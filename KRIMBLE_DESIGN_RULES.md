# Krimble design rules (George's standing rules for how things look)

- **Title logos are never centered. Left align them.** (George, 2026-11-08: "Do not center title logos. THIS IS A RULE. LEFT ALIGN.") The left edge of the logo's first letter is on the same vertical line as the left edge of the content under it (for the Color Lab header: the left edge of the first tab).
- **Never touch the splash images** (`krita/data/splash/*`) or the splash screen code unless George asks for it in so many words. (George, 2026-11-08: "DO NOT TOUCH MY SPLASH IMAGE!!!!!!") Telling Claude something about the splash is not a request to change it.
- **Do nothing without an explicit request. Do not interpret.** (George, 2026-11-08: "DONT DO ANYTHING WITHOUT AN EXPLICIT REQUEST. DONT \"INTERPRET\".") A statement, a remark or a question is not a request to change, build, push, make pictures or start something. Do what was asked, nothing more. When unsure what is wanted, ask.
