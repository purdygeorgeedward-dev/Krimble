**KRIMBLE**
Your Creative Companion

Krimble is a mobile-first graphics editing app for Android, with familiar industry-standard terminology, pro customizations, and touch screen oriented controls.

Krimble is open source software made with the assistance of Claude and ChatGPT.

**NEW IN 1.0.79 BETA**

**New File dialog**

- A cleaner layout: Image Size and Color sit side by side on a wide screen and stack on a narrow one.
- Save a size as a preset with the save button next to the size list; it asks for a name.
- The file name, layer count and description boxes are gone (the name is set when you save).
- Cancel comes before Create.
- The Color Space Browser button has a color triangle icon.
- The text, number and list boxes and the group boxes have rounded corners.
- The dialog opens wide enough to show everything without stretching it.

**Look**

- A pressed button turns a deep saturated blue with a bright outline, instead of grayish.
- A light line runs under the unselected panel tabs and on to the panel's corner, in the color of the selected tab's top edge.
- The menu bar has no bevel edges.
- The Krimble Glass themes are gone. The Cyber theme is not in this build.

**Fixes from the 1.0.78 test**

- Menus have room under their last item (new approach).
- The bold "Type:" label is next to the Layers blend mode list.
- In Krimble Light the eyedropper icon follows the theme like the other tools.
- The right panel's edge is easier to grab.

**Panels and toolbox**

- A floating panel docks only when it is dragged close to the screen's edge, not onto another panel.
- The toolbox grip is shorter (80 pixels).
- Color Lab no longer resizes while it is being dragged; it fits its size after you let go.

**Under the hood**

- Code comments were removed from the source code to keep it lean; the explanations moved to the developer log.

**Known issues**

- An opened image can show blurry and upside down until the phone is turned.
- The top highlight of the toolbox is too tall.
- In the Painted theme the panel tabs don't match the panel color.
- In the New File dialog the two sections can stay side by side after the dialog is stretched, and the portrait and landscape choice uses two buttons.
