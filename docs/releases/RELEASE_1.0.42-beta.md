**KRIMBLE**
Your Creative Companion

Krimble is a mobile-first graphics editing app for Android, a fork of Krita, with familiar industry-standard terminology, pro customizations, and touch screen oriented controls.

Krimble is open source software made with the assistance of Claude and ChatGPT.

**NEW IN 1.0.42 BETA**

- **File > Revert** is back: it goes back to the last saved file (it asks first if you have unsaved changes).
- **File > New:** the window can be made smaller, and there are new size presets: comic pages (original board, live area, trim size), daily strips, digest comics, photo prints (3.5x5 up to 16x20), and the US Letter, Tabloid and Legal sizes now show their inches.
- **Windows fit the screen:** the program's windows (Image Size, Image Properties, Convert to Profile, Split Image...) scroll instead of being wider than the screen, and open without big empty gaps. The JPEG save options and File Info windows fit, and File Info has a robot picture for Author. Save As and Export open taller.
- **Panels:** the lock, float and close buttons sit at the right edge. The toolbox and the side panels have a small tab handle on their edge. **Window > Stack Panels** is new. A floating toolbox is sized to its tools when you detach it.
- **Transform:** Free Transform rotates when you drag outside a corner; Puppet Warp now explains itself.
- **Selection tools** always start on Replace. **Reset Tool Options on Start** is a new item in the last menu.
- **Preferences** have new 3D icons.
- **Type tool:** the extra heading is gone.
- **Content-Aware Fill** tells you which fill it used.
- The Help menu no longer lists the Krita "Benefits" item.

**KNOWN ISSUES**

- **Smudge still takes over the other tools** after you use it.
- **Window > Stack Panels** puts two of the panels side by side instead of one above the other.
- **File > New:** the 3D pictures in the list are too big.
- **The toolbox can get stuck in horizontal mode** while it is being dragged.
- **Free Transform:** the rotate arrows at the corners are too large.
- **Right-side panels** are reluctant to attach to the edge. The toolbox's edge tab is twice as tall as it should be.
- **Content-Aware Fill** is soft on busy pictures; small areas work well.

Fixes for these are already made for the next version.

This is a beta. Please report problems on the Issues page.

**Install:** download the APK below and open it on your phone (arm64 devices).
