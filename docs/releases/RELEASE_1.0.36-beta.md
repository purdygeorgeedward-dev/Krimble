**KRIMBLE**
Your Creative Companion

Krimble is a mobile-first graphics editing app for Android, a fork of Krita, with familiar industry-standard terminology, pro customizations, and touch screen oriented controls.

Krimble is free open source software made with the assistance of Claude and ChatGPT.

**NEW IN 1.0.36 BETA**

- **File > Share...** opens a small window: JPG or PNG, a quality slider (JPG) or compression slider (PNG), a size (original, or longest side 1920, 1280 or 1080 px) and "Flatten onto white". It then opens Android's share sheet. The share symbol is in the menu.

- **Quick Adjust** is now a window, under Image > Adjustments: six sliders (Brightness, Contrast, Saturation, Hue, Lightness, Vibrance) with a live preview, OK and Cancel.

- **Back on for testing:** Image > Upscale..., Image > Batch Process... and Layer > Style Presets.

- **Polygon selection** works with a finger (tap or drag to put down each point, marching ants, drop a point on the first one to close it), with Undo Point, Close and Cancel in Tool Options. Added in 1.0.35.

- **Narrower menus:** the empty column for keyboard shortcuts is gone from menus. Shorter menu names: ShowDrag, Benefits..., Direction...

- **Toolbox and panels:** no minimum widths (the toolbox keeps one column), an invisible grab strip beside each side's panels for resizing, and the toolbox keeps the number of columns you choose, also in portrait.

- **The panel layout is saved** when you leave the app, so a panel you close stays closed.

- **Canvas Only mode** has a black X in the top right corner to leave it.

- **Your own icons** are bigger on the Preferences and File > New lists.

- **Removed from menus:** Where is...?, the Krita Handbook, Layout Presets, Save and Reset Layout, Share as JPG and PNG.

- **File > Take Photo...** is in this build for testing. It opens the camera and then shows an error; it no longer crashes.

**KNOWN ISSUES (found in testing)**

- Panels do not go into tabs when dragged on top of each other.
- Take Photo shows an error after the photo is taken.
- The icons on the File > New and Preferences lists are still small, and the New list is too narrow.
- Brushes opens at launch the first time. Close it once, then leave the app, and it should stay closed.
- Floating windows have small buttons and a teal title bar.
- A long file name still widens the Window menu.
- The Healing Brush message window is very wide.
- A very large brush can make a stroke do nothing, and the brush tool sometimes stops working.
- The Smudge tool acts like a plain brush.
- The default text size is small, and the text box has very large handles.
- The crop tool's corner boxes are large.
- The Photo Edit toolbar has two crop buttons (the Crop tool and Apply Crop).
- The Type Options toolbar is empty when the Type tool is not in use.
- A menu occasionally gets stuck.

This is a beta. Please report problems on the Issues page.
