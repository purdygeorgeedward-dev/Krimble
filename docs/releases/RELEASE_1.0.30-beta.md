KRIMBLE
Your Creative Companion

Krimble is a mobile-first graphics editing app, a fork of the Android version of Krita, with familiar industry-standard terminology, several add-on customizations, and touch screen oriented controls.

Krimble is free open source software made with the assistance of Claude and ChatGPT.

WHAT'S NEW IN 1.0.30 BETA
- New app icon: a larger K with the paw print.
- New Document dialog now fits the screen and scrolls, so Create and Cancel are always reachable. Entry boxes are narrower.
- Toolbox: rotating the screen no longer switches it from 1 column to 2.
- Toolbox: a new Columns choice (1 to 4) in its long-press menu.
- Preferences: a narrower left list, with the section titles wrapped under their icons.
- Targets Android API 36, as Google Play now requires.
- Package size is about 158 MB, same as 1.0.29.

This is a beta. Please report problems on the Issues page.

Install: download the APK below and open it on your phone (arm64 devices).
