**KRIMBLE**
Your Creative Companion

Krimble is a mobile-first graphics editing app for Android, a fork of Krita, with familiar industry-standard terminology, pro customizations, and touch screen oriented controls.

Krimble is open source software made with the assistance of Claude and ChatGPT.

**NEW IN 1.0.43 BETA**

- **Type tool, new window:** tabs for Text, Font, Style and Layout. A favorite star on the font, size and color (with recent colors and a button that takes the foreground color), bold, italic, underline and strike-out, a menu for UPPERCASE, lowercase, Title Case and Sentence case, four alignments including justify, letter spacing, line spacing, kerning at the cursor, and a preview. A searchable font list with favorites. Held sideways, the words and preview sit on the left and the controls scroll on the right.
- **Type tool, frame with handles:** the text you just made or tapped gets a frame. Drag inside it to move the text, drag the round handles at the sides to change the width of the text box, drag the square corners to make the text bigger or smaller. A tap inside the frame opens the window.
- **Content-Aware Fill:** it now fills from the edge inward using real pieces of the picture instead of an average, which should look less blurry. Thin holes, such as wires and hair, are handled better.
- **Smudge:** a new fix for the Smudge brush taking over the other tools.
- **Window > Stack Panels:** rewritten so the panels sit one above the other.
- **Panels:** the toolbox edge tab is half as tall, the right-hand tab has an edge, and right-hand panels attach from twice as far away. The toolbox no longer turns horizontal while you drag it.
- **Start page:** no more mentions of Krita, the DEV BUILD warning, the empty News column and other items nobody used. New Image, Open Image, Recent Images, Support Krimble, Source Code and the Krimble website remain.
- **About > Also Thanks To:** now thanks Claude, ChatGPT, Oracle Cloud, Termux and GitHub, with their logos, and still credits the Krita team and everyone listed in Krita's own credits.
- **Window menu:** Customize Toolbar... moved here, next to Toolbars and Lock Toolbars. Its window is narrower: on an upright phone the two lists sit one above the other.
- **Image > Mode > Indexed Color...:** nine new palettes to pick from: Macintosh 8-bit (256), VGA 256, CGA 16, Windows 16, EGA 64, Commodore 64, Game Boy, Amiga Workbench and Grayscale 16. The Edit Presets window is narrow now.
- **Emoji in the Type tool:** a monochrome emoji font (Noto Emoji) is built in, so emoji should show as shapes in the text color.
- **About Krimble:** no longer enormous: it opens to fit the screen, and held sideways it is two columns.
- **On-screen messages** stay only as long as they take to read, the Content-Aware Fill "done" message no longer appears when it worked, and the Polygonal Selection tool no longer pops up its how-to text.
- **File > New:** the earlier pictures are back (the Preferences icons keep their new look).
- **Free Transform:** the rotate gadgets at the corners are small arrows now.

**KNOWN ISSUES**

- **Not yet seen on a phone:** all of the changes above are new in this build; the Smudge fix and Stack Panels in particular need testing.
- **Type tool:** tapping text can show a red box; the cause is not found yet. Emoji appear in one color only, and parts of a text cannot yet be styled separately (one style for the whole text).
- **Content-Aware Fill** can still look soft on busy pictures; small areas work best.
- **Still to do:** the Quick Mask design and Auto Color.

This is a beta. Please report problems on the Issues page.

**Install:** download the APK below and open it on your phone (arm64 devices).
