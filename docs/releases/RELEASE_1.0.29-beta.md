**KRIMBLE**
Your Creative Companion

Krimble (formerly Krita Mobile) is a mobile-first fork of Krita designed to be a graphics editing app using familiar industry-standard  terminology, pro customizations, and touch screen oriented controls.

Krimble is free open source software made with the assistance of Claude and ChatGPT.
