# Open-license fonts that come with Krimble

Added 2026-10-18. 52 families, picked by George Edward Purdy; files from the Google Fonts repository (https://github.com/google/fonts).

- These fonts are **not** part of Krimble's GPL code and are **not** Purdy Design fonts. Each is under its own open license: the **SIL Open Font License 1.1** (OFL) or the **Apache License 2.0**. Both allow use for any purpose, commercial included, and allow them to be bundled with software. They may not be sold by themselves.
- The license of every family is in `licenses/` (file name: family, then license). The copyright notices inside the font files are kept.
- **Modified** (allowed by their licenses; the result keeps the same license): fonts without a Reserved Font Name were cut to Latin characters (Latin, Latin Extended A/B and Additional, punctuation, currency, arrows, math, shapes), and variable fonts among them were turned into fixed Light, Regular and Bold styles (and Saira Expanded). **Not modified:** every font whose OFL names a Reserved Font Name is shipped exactly as published, because the OFL forbids modified versions from using that name. Files of variable fonts were only renamed (`[wght]` to `-VF`), which does not change the font.
- Held out: Merriweather (its only published form is a 9 MB variable font with a Reserved Font Name, so it cannot be slimmed).
