# Thank-you icons

Used in the "Thank you" section of the main README.

- `claude.svg`, `openai.svg`, `oracle.svg`, `github.svg`: the glyphs come from [Simple Icons](https://simpleicons.org) (released under CC0 1.0), drawn here in each brand's colour on a white rounded square. The OpenAI and Oracle glyphs are from Simple Icons release 13.0.0 (they were removed from later releases).
- `termux.svg`: the Termux launcher icon from the [termux-app](https://github.com/termux/termux-app) repository (`art/ic_launcher.svg`), unchanged. That repository is released under GPLv3.

The logos and names belong to their owners (Anthropic, OpenAI, Oracle, GitHub and the Termux project). They are shown only to say thank you. Their owners have not endorsed Krimble.
